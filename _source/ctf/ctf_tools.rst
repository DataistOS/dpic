ابزارهای کمک‌کننده چالش‌ها (Helper Tools)
========================================================================

برای موفقیت در چالش‌های فتح پرچم (CTF) و تحلیل رفتار سیستم، آشنایی با جعبه‌ابزارهای تخصصی ضروری است. در اینجا لیست کاملی از ابزارهای کلیدی برای سناریوهای مختلف آورده شده است:

دستورات پایه و حیاتی (Foundation Commands)
------------------------------------------------------------------------

این دستورات، اولین سلاح‌های شما برای کشف و استخراج اطلاعات در محیط لینوکس هستند.

* **grep:** جستجوی الگوهای متنی. (مثال: ``grep -r "DPIC{" .``)
* **find:** جستجوی فایل‌ها بر اساس نام، اندازه یا دسترسی.
* **strings:** استخراج رشته‌های متنی از فایل‌های باینری.
* **awk / sed:** پردازشگرهای قدرتمند متن برای ویرایش خروجی‌های شلوغ.
* **hexdump / xxd:** مشاهده محتوای فایل‌ها به صورت هگزادسیمال.
* **chmod / chown:** مدیریت سطوح دسترسی و مالکیت فایل‌ها.
* **lsof:** لیست کردن فایل‌ها و پورت‌های باز شده توسط پروسه‌ها.

جرم‌شناسی دیجیتال (Forensics)
------------------------------------------------------------------------

ابزارهایی برای تحلیل فایل‌ها، بازیابی داده‌ها و بررسی شواهد.

* **ExifTool:** خواندن و ویرایش متادیتا (Metadata) فایل‌ها.
* **Foremost:** استخراج فایل‌های خاص بر اساس هدرها (Headers).
* **Wireshark:** تحلیل فایل‌های pcap و ترافیک شبکه.
* **Audacity:** تحلیل فایل‌های صوتی (استگانوگرافی صوتی).
* **Pngcheck:** بررسی یکپارچگی فایل‌های PNG.
* **Volatility:** بررسی و تحلیل دامپ‌های حافظه (Memory Dumps).
* **USBRip:** ردیابی دستگاه‌های USB متصل‌شده.
* **BinWalk:** تحلیل و استخراج فایل‌های فشرده درون فریم‌ورها.

شبکه (Networking & Attacks)
------------------------------------------------------------------------

ابزارهای کشف شبکه، اسکن پورت‌ها و حملات شبکه‌ای.

* **Nmap:** ابزار استاندارد برای کشف شبکه و بازرسی امنیتی.
* **Masscan:** اسکنر پورت‌های TCP با سرعت بسیار بالا.
* **Zeek:** ابزار مانیتورینگ امنیت شبکه (Network Security Monitor).
* **Bettercap:** چارچوبی برای اجرای حملات MITM.
* **Yersinia:** ابزار حمله به پروتکل‌های لایه ۲.

وب (Web Exploitation)
------------------------------------------------------------------------

ابزارهای تخصصی برای کشف آسیب‌پذیری‌های وب.

* **BurpSuite:** ابزار پراکسی رهگیری برای تست امنیت وب.
* **SQLMap:** تزریق خودکار SQL و کنترل دیتابیس.
* **Commix:** ابزار خودکار برای تزریق دستورات سیستم (OS Command Injection).
* **Hackbar:** افزونه مرورگر برای تست سریع آسیب‌پذیری‌های وب.
* **OWASP ZAP:** جایگزین متن‌باز برای اسکن و فازینگ HTTP.

بروت‌فورسرها (Bruteforcers)
------------------------------------------------------------------------

* **Hashcat:** قدرتمندترین کرکر پسورد مبتنی بر GPU.
* **Hydra:** ابزار لاگین‌کرکر موازی با پشتیبانی از پروتکل‌های متعدد.
* **John The Ripper:** ابزار کلاسیک کرک پسورد.
* **Patator:** بروت‌فورسر چندمنظوره و ماژولار.

مهندسی معکوس (Reversing)
------------------------------------------------------------------------

* **GDB / GEF / Pwndbg:** دیباگرهای استاندارد لینوکس و افزونه‌های آن.
* **Ghidra:** چارچوب کامل مهندسی معکوس (توسعه یافته توسط NSA).
* **Radare2:** چارچوب کامل برای تحلیل باینری‌ها.
* **Pwntools:** چارچوب پایتونی برای نوشتن اکسپلویت.
* **Frida:** ابزار پویا برای تزریق کد (Dynamic Code Injection).

.. tip::
   همیشه پیش از استفاده از ابزارهای پیچیده، سعی کنید با دستورات پایه لینوکس مسئله را حل کنید. برای یادگیری عمیق‌تر مفاهیم هر ابزار، حتماً از [CTF-Wiki](https://ctf-wiki.org/) استفاده کنید. این مخزن به صورت مداوم بروزرسانی می‌شود؛ اگر ابزار جدیدی مد نظر دارید، پیشنهاد خود را برای ما ارسال کنید.
